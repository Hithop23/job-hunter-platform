## Brand & Style

The design system projects extreme technical precision, high-velocity intelligence, and uncompromised executive polish. Built for ambitious professionals navigating algorithmic hiring pipelines, the interface feels like an intelligence cockpit rather than a traditional administrative tool.

The visual direction merges **Technical Minimalism** with **Hyper-Refined Modern Dark Mode**. It rejects generic dashboard tropes in favor of structural clarity, high-density data surfaces, surgical hairline borders, and targeted luminescent accents. Emerald and mint signals represent algorithmic validation, high-confidence match scores, and automated optimization progress against deep, layered slate foundations.

Interactions are immediate, crisp, and predictable. Data viz, live scoring gauges, and parse states emphasize analytical certainty. The interface feels confident, discreet, and computational.

## Colors

The color system relies on high-contrast hierarchical dark layers paired with luminous emerald accents that strictly communicate system intelligence, ATS readiness, and critical user actions.

### Surface Tiers
- **Canvas Base (`#0B0F17`):** The primary view background, framing analytical panels and document canvas viewports.
- **Surface Elevation 1 (`#111827`):** Side panels, structured containers, metric clusters, and persistent utility drawers.
- **Surface Elevation 2 (`#1E293B`):** Hover states, interactive dropzones, inner cards, and segmented control wells.
- **Surface Highlight (`#334155`):** Structural 1px hairline dividers, card bounding boxes, and active focus boundaries.

### Accents & Signal Colors
- **Emerald Primary (`#10B981`):** High-confidence ATS scores (85%+), primary execution buttons, and active pipeline checkpoints.
- **Mint Luminous (`#34D399`):** Accent glow, subtle highlight borders for matched keywords, AI suggestion tags, and pulse badges.
- **Deep Emerald (`#059669`):** Pressed button states and high-density progress fills.
- **Warning Amber (`#F59E0B`):** Moderate ATS alignment (60%–84%) and non-fatal keyword gaps.
- **Critical Coral (`#EF4444`):** Syntax parse errors, missing requirements, and fatal formatting red flags.
- **Text & Content Hierarchy:** Primary text is `#F8FAFC`, secondary descriptive text is `#94A3B8`, and disabled/auxiliary labels use `#64748B`.

## Typography

The typographic hierarchy pairs the structured, modern geometric stance of **Plus Jakarta Sans** for display anchors, major statistics, and metric headings with the neutral utilitarian legibility of **Inter** for dense resume prose, parameter tables, and keyword diagnostics.

- **Numbers & Metrics:** Numeric readouts in ATS score meters and metric cards utilize tabular figures (`tnum`) to eliminate layout jitter during live calculations.
- **Code & Syntax Fragments:** ATS token placeholders and raw resume markup preview snippets employ standard monospace styling at `0.8125rem` with a fixed line height of `1.25rem`.
- **Vertical Rhythm:** Headings enforce tight negative letter-spacing to enhance technical polish, while body and metadata tokens feature open line height to maintain effortless scan-readiness across split-pane views.

## Layout & Spacing

This design system employs an adaptive fluid-to-fixed grid built specifically for dual-pane analytical productivity:

- **Desktop Workspace (1280px+):** A 12-column layout designed around an asymmetrical split: a 5-column job target/intelligence stream and a 7-column real-time resume editor with floating contextual toolbars. Desktop margin is set to `2rem` with `1.5rem` gutters.
- **Tablet (768px – 1279px):** Collapses into a tabbed dual-view interface with an 8-column layout, `1.5rem` margins, and `1.25rem` gutters.
- **Mobile (<768px):** A single 4-column flow with persistent bottom-anchored action docks and sticky top-tier score gauges. Screen margin is constrained to `1rem` with `1rem` gutters.

Spacing tokens follow a strict 4px/8px cadence:
- `space-2xs` (4px) and `space-xs` (8px) govern micro-interactions inside pills, buttons, and keyword chips.
- `space-sm` (12px) and `space-md` (16px) separate internal card modules, input field groups, and stepper intervals.
- `space-lg` (24px) through `space-2xl` (48px) separate overarching dashboard sections and diagnostic panels.

## Elevation & Depth

Depth is established primarily through **Tonal Layering** and **Crisp Structural Hairlines**, avoiding heavy, muddy drop-shadows typical of light designs:

1. **Level 0 (Floor):** Solid `#0B0F17`. Non-interactive backgrounds, grid margins, and deep viewports.
2. **Level 1 (Card & Module Shells):** `#111827` bordered with a 1px solid border of `#334155` at 60% opacity. 
3. **Level 2 (Floating Popovers & Modals):** `#1E293B` elevated with an ambient dark blur: `0 12px 32px -4px rgba(0, 0, 0, 0.65)` combined with a sharp hairline border of `rgba(255, 255, 255, 0.08)`.
4. **Active Luminescence (AI Focus & High Score Highlights):** Interactive components in successful states utilize a targeted mint glow: `0 0 20px -4px rgba(16, 185, 129, 0.25)` and a subtle interior border glow `inset 0 0 0 1px rgba(52, 211, 153, 0.4)`.
5. **Glass Overlays (Export & Floating ATS Dock):** Frosted glass surfaces combine `rgba(17, 24, 39, 0.75)` with `backdrop-filter: blur(12px)` and a top edge highlight line `inset 0 1px 0 0 rgba(255, 255, 255, 0.1)`.

## Shapes

The system uses a balanced geometric radius curve (`roundedness: 2`), projecting technical competence without clinical brutality:

- **Base Radius (0.5rem / 8px):** Standard interactive elements including input fields, drop-down menus, table rows, button baselines, and code snippet wells.
- **Large Radius (`rounded-lg` / 1rem / 16px):** Metric panels, job detail cards, ATS gauge pods, and modal shells.
- **Pill Radius (`rounded-full` / 9999px):** Status badges, match-score chips, step indicators, and circular quick-action icons.

## Components

### Buttons
- **Primary Action (Run AI Optimizer, Apply Fixes):** Surface `#10B981` with high-contrast text `#0B0F17` (semibold). Hover shifts to `#34D399` with a subtle `0 0 16px rgba(16, 185, 129, 0.35)` bloom. Active state drops to `#059669`.
- **Secondary (Inspect Breakdown, Add Section):** Surface `#1E293B`, 1px border `#334155`, text `#F8FAFC`. Hover state brightens border to `rgba(255, 255, 255, 0.2)` and background to `#334155`.
- **Ghost (Icon Triggers, Export Option Rows):** Transparent surface, text `#94A3B8`. Hover state fills with `rgba(30, 41, 59, 0.6)` and shifts text to `#F8FAFC`.

### Chips & Match Badges
- **Pill Badges:** Fully rounded (`rounded-full`), height of 24px, padding `0 10px`. 
- **High Match / AI Keyword Chip:** Surface `rgba(16, 185, 129, 0.12)`, border `1px solid rgba(16, 185, 129, 0.3)`, text `#34D399`, font size `label-xs`.
- **Missing Keyword Chip:** Surface `rgba(239, 68, 68, 0.1)`, border `1px dashed rgba(239, 68, 68, 0.35)`, text `#F87171`. Includes a subtle `+` affordance to auto-insert into content.

### Interactive Stepper
- Horizontal progression track using 2px connecting rails (`#1E293B` inactive, `#10B981` completed).
- Step nodes are 32px circles. Completed nodes are solid `#10B981` displaying an icon checkmark. Active nodes feature an outer `#111827` halo with a 2px `#10B981` ring and pulsing center dot. Future steps are static `#1E293B` with `#64748B` typography.

### Live ATS Score Gauge
- Concentric circular gauge with a stroke width of 8px.
- Background track is `#1E293B`; active arc is an emerald gradient from `#059669` to `#34D399` with rounded caps.
- Center typography displays numeric value in `Plus Jakarta Sans` 700 with a secondary micro-label (`MATCH INDEX`).
- Live updates trigger an instant counter animation accompanied by an ambient emerald glow transition.

### Job Target Cards
- Base surface `#111827`, hairline border `#334155`, padding `space-md`.
- Layout hosts company mark, job title, and salary metadata alongside an anchored top-right score pill.
- Hover changes the border to `#34D399` at 50% opacity and lifts the card along the Y-axis by 2px.

### Input Fields & Search Bars
- Background `#0B0F17` framed by a 1px border of `#334155`. Height 40px, padding `0 12px`.
- Text is `#F8FAFC` with placeholder `#64748B`.
- Focused state transitions border directly to `#10B981` with an inner shadow ring of `0 0 0 1px #10B981`.

### Checkboxes & Segmented Toggles
- Checkboxes: 18x18px, rounded 4px, `#0B0F17` surface, `#334155` border. Checked state renders `#10B981` background with `#0B0F17` bold check mark.
- Segmented Toggles (e.g., Code View vs. Preview): Contained pill well in `#0B0F17` with active segment rising on `#1E293B` with crisp hairline outline and bright text.

### Document Export Controls
- Docked or floating toolbar using frosted `#111827` with 12px blur.
- Format selector (PDF, DOCX, Plain Text ATS) formatted as a unified button group separated by `#334155` vertical divider lines.
- One-click "Optimize & Export" CTA pinned with an emerald sparkle indicator.
